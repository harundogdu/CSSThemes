# CSSThemes

A collection of static HTML/CSS templates and practice projects built with plain CSS and Bootstrap. Each folder is a standalone site or page layout, not a shared component library.

## Tech Stack

- HTML5
- CSS3 / SCSS
- Bootstrap 4
- Vanilla JavaScript / jQuery

## Structure

- `Bootstrap4_AlbumTemplate/` - Bootstrap album/gallery layout
- `Bootstrap4_BlogTemplate/` - Bootstrap blog layout
- `Clean Blog Template/` - Blog template with SCSS source files
- `Clean Blog/` - Simpler blog page variant
- `MyFirstWebSite/` - Early practice site with Bootstrap and custom CSS
- `Portfolio Script/` - Personal portfolio page template
- `Trial Design/` - Standalone landing page design

Each directory can be opened directly by loading its `index.html` in a browser.
